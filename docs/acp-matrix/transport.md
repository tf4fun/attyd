Upstream SDK snapshot `d5e8bf4d17eafed81b2185acd4bd366e88a33dd1` is 3.4.0 and
uses schema 1.12.0; latest Zed uses the same versions. Changes to native transport
feature flags, prepared-request APIs and raw-error/HTTP internals are SDK migration
work, not new client business features. Native `process`/`stdio` are explicit
features in 3.4.0; the project's 2.0.0 declarations cannot simply be copied on an
upgrade. Schema/MCP and new v1 content differences are inventoried in domain
appendices. Do not apply the new MCP profile to an old 1.7 connection.
