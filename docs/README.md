# 文档导航

本目录按“契约、实现、证据、使用”分工。同一规则只在其权威文档中定义，
其他文档引用它；历史方案不再作为当前实现约束。

## 当前工作

按两个阶段推进：

1. **ACP → bridge**：先完成普通 ACP 客户端功能及可展示的权威内存状态。
2. **bridge ↔ 表现层**：再完成项目自定义的 **简易 Agent 交互协议**，
   解决完整同步、校验与不一致修正。

两阶段都保持 KISS、无持久化和通用 ACP 客户端边界。
实施进度只在 [迁移计划 §7](state-sync.md#7-fidelity-migration-revision-2) 维护；
固定比较版本见 [来源和版本](acp-bridge-matrix.md#1-来源和版本)。
“目标”“已有路径”“测试通过”是不同状态，不能相互替代。
